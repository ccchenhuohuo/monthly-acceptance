# 月度大盘数据验收报告骨架（0.0.1）

这是写作骨架，不是需要逐栏填完的调查表。将业务内容写入 `report-content.json` 后用冻结脚本 `render`，字段见 [报告写作](../references/report-writing.md)。删除提示文字，不凑章节或问题数量。

## 当前结论与使用边界

以国家、平台、连续月份、数据层的全景起笔。说明实际已完成范围、最重要的已证问题和未决限制。整月验收尚未完成时明确“阶段进度”，不以工程测试或局部主审替代。

## 重点问题

按议题台账的正文位置展开。每题保留国家×事件的独立范围与反向分量，串起观察、完整分母、对大盘的影响、证据与竞争解释、当前判断和下一步。

- 观察变化：SPU、销量、本币金额及适用价格带，注明基期、正负分量和无观测状态。
- 已证错误影响：只列经证据支持的错误对象与影响；普通变化与敏感性分析不冒充错误。
- 未解决质量风险：具体缺口、可算范围、未知及其对判断的限制。
- 反证与边界：已经核对的替代解释、原始定位和不能推出的结论。
- 下一核查：对象、月份、记录持有人、需补凭证及停止条件。

## 补充核查与辅助观察

沿 `brief / appendix` 位置简述。微观细节放证据链接；纯分类语义不做专项。更换报告位置不解除已登记议题的质量调查责任。

## 检查覆盖、限制与续跑

按七条主线说明实际已查与未查边界。列客观检查、分区阅读、样本、历史、内部对账、发布承接和未完成门槛；查询成功不能替代业务核验。

分别交代议题数、独立范围数、实际分派数、已主审、已核实、外部受阻和待查。已证缺陷、修复复验、工程完成与业务放行分别表述。

## 证据与成本

引用原始证据、完整范围、实际复算和当前主审。披露查询、分页、复用、重试与真实计时边界；未知 token/费用不估算。旧冻结运行读取其自己的脚本、模板和协议。

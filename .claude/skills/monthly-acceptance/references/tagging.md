# 打标质量

标准类目（std_category_1..3）与属性标签由服务商按「VIJIM类目映射准则」打在每一行上。打标错会直接改变我们看到的类目规模、份额和趋势，所以打标正确性是验收范围的一部分。

## 判定依据

- `RUN/inputs/标准/判定标准.md`：每个叶子的类目定义、机判规则、适用标签，开工时由 `scripts/taxonomy.py` 从飞书冻结。判定以类目定义为准；机判规则是多词共现时的裁决顺序（例如“标题含自拍杆且可伸缩延长的归手机自拍杆，即使同时含三脚架”）。
- `RUN/inputs/标准/说明文档.md`：分级轴体系与标签设立依据。要点：树三级封顶；L1 按功能域、L2 每个一级类目声明一根轴、L3 按形态；标签装好判定的参数轴，不进份额分母；属性识别准确率允许低于类目层，按高销头部优先保障。
- 治理层冻结的映射版本与属性策略（views/17、18）：结构是否合法以它们为准。
- 定义里写明“不纳入统计”的商品应落在“其他”：纯装饰性手机壳不进手机保护壳；大众消费类耳机不进耳机；电动增稳手持云台不进相机配件/云台。
- 判定标准末尾的“准则裁定”是写进飞书之后双方又定下的（来自 `验收/准则裁定.md`，开工随标准一起冻结），优先于定义字面。例如数据线归手机充电；残差叶不要求逐个备注实际形态。已经裁定过的事不再写成标准问题，也不向服务商要。

## 五个子项

| 子项 | 怎么查 | 什么算问题 |
|---|---|---|
| 结构合法 | 摘要第一节 | 路径不在映射版本里；属性取值不在受控集；属性打在不适用的叶子上 |
| 打标完整 | 摘要第二节；`untagged.sql`、`platform_path_detail.sql` | 未打标的行带可观销量；本该关注的商品被打成“其他”掉出口径（看“其他”分流候选的明细标题） |
| 打标正确 | 抽样 `views/13_tag_sample.csv` + 变化驱动商品；整叶看摘要第六节的平台类目构成 | 商品与所在叶子的定义不符 |
| 打标一致 | 摘要第三节；`spu_trace.sql` | 同一 SKU 无理由跨月换叶；同父体子体被劈到互斥叶子 |
| 属性标签 | 摘要第五节 | 适用叶子上填充率骤降或长期异常低；取值越界 |

## 抽样判定

1. 样本：每个国家×平台×三级叶子取件数前 3（头部必核）加打散后的 2 个，“-其他”残差叶取前 10。另外，模块 4 下钻得到的每个变化驱动商品都必须核。
2. 逐条读中文标题（title_cn，Amazon 为服务商翻译）与平台路径；中文含糊、为空或与路径对不上时读原文标题（title_raw）。
3. 计法。每个国家×平台必须一致，否则不符率不可比：
   - **不符**：商品与现叶子的定义说不通。应归叶子明确就写叶子或“其他”，不明确写“待定”，仍计不符。
   - **存疑**：标题信息不足以判断，写明缺什么。
   - **符合**：其余。
   - **准则问题**是另一列，可与任一结论同时出现：准则边界不清、两叶互相覆盖，或某类商品该不该纳入没写。现叶子按定义字面说得通的（例如消费音箱在音视频类-其他、桌面手机支架在支撑类-其他），结论记“符合”并标准则问题，不计不符。
4. 样本多时按国家×平台开子 agent 并行判。任务书给：判定标准全文的路径、该国家×平台在 `views/13_tag_sample.csv` 里的行、第 3 步的计法；子 agent 不连库，不读历史台账、案例库与往期报告。交回 `RUN/queries/打标判定_<站点>_<平台>.csv`，列为 `l1, l2, l3, product_id`（照抄样本）、`verdict`（符合 / 不符 / 存疑）、`rule_issue`（是 / 否）、`target`（应归）、`basis`（依据的定义原句）、`note`（标题摘要与说明）；说明文字可另写同名 .md。
5. 主 agent 复核件数最大的不符项，对照原文标题与平台路径，复核依据后才采信。然后跑 `python3 scripts/tagging.py RUN` 汇总，按样本组（头部 / 残差叶 / 随机）算不符率，结果在 `queries/打标判定_汇总.md`。
6. 一个叶子的头部样本出现不符，先看 09 摘要第六节里该叶的平台类目构成（全量在 `views/20_leaf_paths.csv`）。错分商品集中在某些平台节点时，按这些节点的件额估整叶错分占比，结论写“按平台类目估”。错分与平台节点无关时（按标题关键词落叶、同一节点里混杂），由主 agent 用 `leaf_sample.sql` 扩抽该叶子（例如排名 4–30），不扩到不相干的叶子。
7. 残差叶要看是否吸走了具名兄弟叶的商品，看它的平台类目构成和样本。准则规定“-其他”桶连续两个季度超过父级约一成或同类聚集成量时，应评审升格。

## 影响判断与写法

- 量化：错分商品在所在叶子当月的件额与占比、对叶子变化的贡献、是否改变叶子或父类的趋势方向与价格带结论；被打出口径的商品同样量化对关注口径的漏计。
- 单列进重点问题：错分改变了某个类目四项结果的判断，或同一机制成片出现。其余汇总为打标质量指标（样本不符率、按叶子列的不符清单）放进“需服务商核对的事项”。
- 写给服务商时给 product_id、平台路径、现叶子、应归叶子和依据的定义原句；不写处置。
- 准则本身有疑义（定义边界不清、两叶互相覆盖）的，写成给用户的标准问题，不算服务商缺陷。

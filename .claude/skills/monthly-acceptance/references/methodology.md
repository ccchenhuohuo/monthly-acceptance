# 从全景判断质量疑问（0.0.1）

先读国家、平台、月份、数据层及全部类目轨迹，再对具体质量疑问使用以下计算。调查与完成边界以 [问题协议](question-workflow.md) 为准；普通市场波动不生成逐对象解释义务。

## 1. 四项结果与粒度

每个国家分别观察，淘宝与天猫保留独立身份和质量总体，展示可合并。SPU 用 product_id（Amazon parent_asin），规格细行保留原始身份用于查错。先确认原始粒度、同键重复和映射是否放大；不靠随意 DISTINCT 或删行制造守恒。

同一 SPU 的子体可分属不同类目：类目内汇总对应子体，不能将整个父体销量重复赋给多个类目；上级/全站 SPU 数独立去重，不加总各子类目商品数。ID 稳定也要留意历史商品内容和标签变化。

SKU 为 NULL、空白或“0”时，不把占位值当作跨父体的共同商品身份。同父体历史记录和量额继续保留，但不能直接认定两个时期的售卖规格相同；先做完可行的父体、来源和量价核对，缺少身份桥接凭证的对象仍保留未核影响。

| 结果 | 观察什么 | 解释时区分 |
|---|---|---|
| 类目 SPU 数量 | 有效商品数、出现/消失、映射与范围 | 新品、采集变化、归属变化；缺少记录不代表退市 |
| SPU 价格带 | 同国同类目固定边界下各带 SPU 数、销售额及份额，未知价格单列 | 同款变价与商品/销售结构变化；均价不能替代分布 |
| 销量 | 总件数、同比/环比、细分类目与 SPU 的增减贡献 | 同款起量/回落、供需与采集估算变化；金额平稳也可能有量价抵消 |
| 销售额 | 总额、同比/环比及变化贡献，量价作为解释 | 真实需求、促销、供给结构与数据缺陷 |

单 SPU 的观测成交均价用汇总销售额/销量；它可能是拟合值。零/负量价、金额缺失、异常原始键需保留并核验，不能无声丢掉；价格未知的商品仍计入有效 SPU 与金额总量，另列其分布状态。

## 2. 贡献决定先查哪里

设同国同父类目两期销售额为 C₀、C₁，一个互斥子集（子类目/品牌/SPU）的销售额为 A₀、A₁：

- 子集变化金额 ΔA = A₁ − A₀；类目变化金额 ΔC = C₁ − C₀。
- 对净增减的贡献 = ΔA / ΔC；正负有意义，可超过 100%。当 ΔC 为零或接近零时不据该比值排名，先看正负抵消与绝对金额。
- 对类目增长的百分点贡献 = 100 × ΔA / C₀；C₀ 为零时不定义。
- 辅助看 |ΔA| / Σ|ΔAᵢ| 定位相互抵消下的主要变动，以及子集销售额占类目的份额。份额与变化贡献回答不同问题。

示例：类目 1,000 万→1,500 万；待核验产品 200 万→650 万。它们贡献 450 万，解释净增额的 90%，贡献类目增长 45 个百分点。少量商品即可决定大盘结果，优先级应前移。**此时只定位了变化，还没有证明这 450 万都是错误。**

同一父类目内对互斥子集分解，保留全部正负状态，合计应还原父类目增减；不要把 L1/L2/L3 重叠影响重复相加，或在算父类目分母前过滤疑似商品。缺失子集可按观测集合份额为零参与分解，但需同时标注未观测，不能说真实销售为零。

若已取得可信纠错值，分别记录两期错误额 E₀、E₁，错误对变化的影响为 E₁−E₀，并用 (C₁−E₁)/(C₀−E₀)−1 比较修正增长。只排除一组商品的前后两期属于**敏感性分析**，改变了观察集合，不能冒称修正后的真实类目规模；不要只删当期异常而保留基期。

销量按相同分解方式单独计算增减件数、净贡献和增长百分点。异常排序同时看销量与金额，不能只按金额排序：量增价跌、量跌价涨可能使金额稳定；说明哪项结果受影响，避免用一个混合分数掩盖它。

优先查会改变类目趋势方向/幅度、主要价格带或 SPU 规模判断的局部问题；销量/金额贡献和其余两项结果影响分别披露。原始范围漏采另行核对，不能以暂无 std 暴露掩盖它。

## 3. 完整聚合，按问题决定微观范围

先看完整连续轨迹、全部正负贡献与 SPU 进出，不能用 Top N 代替全景。具体疑问形成后，优先用同口径聚合区分解释；身份、放大、历史对象或量价机制需要时再取完整 cohort 或明细。

同一事件保留反向分量和恢复时期。既定合同中的范围不能被低金额或低贡献悄悄排除；但普通变化和未立案对象没有通用市场原因解释义务。所声称的错误对象及其影响必须有完整证据。未决质量问题继续，已排除的具体疑问按有效主审关闭；停止不取决于解释率或数量配额。

## 4. 结果是线索，检验具体质量解释

| 观察到的结果 | 可检验的解释，不是结论 |
|---|---|
| 金额平稳、销量大幅变化 | 量价抵消、商品组合迁移或价格/销量错误；销量仍须单独排查 |
| 金额上涨、SPU 数稳定 | 同款销量/价格变化、活动、需求、结构迁移、模型调整 |
| SPU 数增加、金额几乎不动 | 真实上新/铺货、低销尾部补采、标签/父子体变化；先量化数量与价格带影响 |
| 价格带份额迁移 | 同款优惠、头部组合变化、不同价位新品、漏采或抓价错误 |
| 少数子类目/商品解释大部分涨跌 | 先查主要贡献者的活动、生命周期及原始量价，不以集中度直接判错 |
| 多类目、品牌持续同涨 | 真实需求或共同数据机制均可能；结合场景、持续性和范围/拟合变化反证 |

地区日历按年份核对实际节日和活动，并结合品牌定位、实际优惠、上新/铺货与使用季节；销量可提前或滞后。只有节日名称不能解释变化，淡季上涨也不能直接判错。

**必要的外部交叉核验。** 仅在能够区分当前质量疑问的解释时使用；纯市场研究走受治理的 flywheel 通道。从待核结果出发，自由提出并修订假设；外部变化既可能是有明确时点的事件，也可能是文化、技术、使用习惯和市场结构的逐步演变。以下组织的是推理过程，示例不限定可探索的原因。

- 明确问题：哪些国家、时期、类目与 SPU 的哪项结果改变了，主要贡献在哪里？检索围绕这个问题展开。
- 生成假设：什么让人们产生或减弱需求、改变使用场景、购买能力/意愿、产品供给或交易方式？任何有依据的新机制都可提出，允许多种解释竞争。
- 展开传导：外部变化如何经行为、供给或交易结构传到具体商品的四项结果？说明若假设成立，应在哪些对象和时段看到什么；考虑突发、渐进、提前与滞后，而不是寻找一条时间重合的新闻。
- 检验证据：按传导环节选权威公开资料与原始数据，核对方向、持续性和作用范围，主动寻找不符合预期的观察；必要时比较受影响不同的地区/商品。依据新证据修订或放弃假设，取证口径见 `cross-validation.md`。
- 回到观测边界：整体需求、渠道份额迁移和采集可见性/映射变化分别核对，可同时发生。平台交易增长未必等于行业需求增长；平台规则变化既可能改变真实交易，也可能改变采集条件。份额证据需同国、同类目、同期间、同指标，不能用平台总体份额替代类目份额。

趋势方向、持续性与范围得到支持，不代表具体涨跌幅已被解释；不编系数、不机械扣除事件/促销/季节效应，也不因找到一个故事就消除数据疑点。可信源数据证据确认缺陷后，按四项结果影响写入最终审计报告；未回答的质量疑问保留待核；普通市场原因未知不自动要求扩查。外部研究以能否改变当前判断或下一步取证为限，不为凑齐原因清单持续扩张。

逐层回到源数据验证身份、完整路径、重复、映射、量价关系及估算依据；未解释不等于错误，贡献不等于因果。本品内部对拍可能与服务商校准同源，匹配只是必要旁证。

## 5. 范围、消费影响与报告深度

全历史同时核对类目存在状态与有效采集范围。首次观测可能是补漏；末端无记录只表示截至窗口未恢复；应有但从未出现的类目需从项目范围引入，不能只依赖现有数据集合。区分公司 std、平台完整路径及有效变更，必要时按问题用外证核对平台节点。

报告优先回答四项结果是否受到实质影响，贡献多大、结论是否改变；再说明源层问题是否传入公司 std 与实际治理发布面。无观察、确认未传入和检查未发现异常是不同状态。

主要问题给到具体国家、月份、父类目、贡献子集和源数据证据；低影响尾部集中列风险。净变化小也要检查重要正负抵消，范围守门不因结果平稳而取消。检查边界、剩余不确定和下一步需要的证据如实说明。

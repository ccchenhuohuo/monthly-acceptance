# 按具体问题补充外部证据

仅在外部证据能够区分当前质量疑问或改变其下一步时使用。普通市场波动不要求补齐全部驱动解释；纯市场研究走受治理的 flywheel 通道。

## 外部市场变化：按假设寻找证据

以本次国家、时期、类目、主要贡献商品和待验证机制决定检索问题，开放探索突发变化与渐进趋势。来源随问题选择：政府/统计机构披露、平台规则与经营数据、厂商公告、方法透明的原始研究及有来源的权威报道均可提供不同环节的证据；这不是来源或驱动类型的封闭清单。区分声明、市场行为证据和分析推断，核对来源独立性；宣传热度、内容浏览量或宏观总指标不能直接代替具体商品的购买与成交。

有明确节点时区分宣布、生效、当地开售/促销与传导窗口；渐进变化看连续观察期、受影响人群/场景和持续性，不硬指定一个事件日。保留统计期、披露/检索日期和修订版本；历史问题按相应阶段检索，事后修订/追溯信息需注明。核对地域、对象、指标、名义/实际与季调口径，保存链接和必要证据到本次 evidence。

沿假设的中间环节核对预期对象、时序、方向和反例，说明证据支持、削弱或尚不能回答什么。平台份额必须核对同类目等分母边界，并分别判断真实交易迁移与采集条件变化；不能从所采平台直接外推全行业。证据不足时调整假设或保留待核，不凭时间重合推算影响倍数；已能确认的数据缺陷及时形成审计发现，研究范围随决策价值收敛。

## 商品与节点：按需 Sorftime

Sorftime CLI 用于 Amazon 的平台节点、完整路径、代表商品或趋势核验；在能改变合理性判断、优先级或置信时使用。先缩小问题，不逐类目扫描，不用第三方数字替代受治理的市场出数。淘系问题按适用的内部/平台证据判断，不调用 Amazon 工具。

调用前明确要回答的问题和对象：是范围漏采、路径迁移、父子体归属，还是主要贡献商品的量价趋势？查看项目配置及已安装 `sorftime-research`/CLI 的当前帮助、端点与计费；不把旧命令、固定费用和猜测字段复制进执行。项目已有费用授权按其范围沿用；未获授权的收费调用按配置先说明端点、对象和总消耗再取得授权。密钥由 CLI 托管。

取证与解释：

1. 对齐国家、父体/子体、日历月/滚动窗口、币种、指标定义、更新时间和端点覆盖。一个子体不代表整个 SPU；当前节点存在不能证明历史范围完整。
2. 核对来源独立性。供应商可能采用过同一来源或用内部数据校准；相符只证明相应口径一致，不额外提供一份独立真值。
3. 记录实际输出和覆盖限制。空响应、无权限、查询错误、端点不覆盖与真正无观测分别处理；不可当作零。
4. 说明外证支持或削弱了哪项解释。分歧提示继续排查，不直接认定任意一方错误；同向也不能单独证明真实需求。

内部已能复现的计算/映射错误，或对四项结果均无实质影响的尾部，不为凑证据额外调用。报告保存查询对象、口径与证据位置，不扩成通用 API 手册。

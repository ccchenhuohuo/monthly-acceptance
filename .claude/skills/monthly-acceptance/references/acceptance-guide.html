大盘数据验收：先全景，再调查议题

当前全景与议题架构流程导航（0.0.1）。当前安装版本见 Skill 入口，具体合同与命令以 权威协议 和本运行冻结脚本为准。本页不表示真实运行进度。

执行路径

  1. 冻结国家、平台、历史月份、数据层和预期范围；完成原生分页查询。
  2. 保留连续全景和全部客观检查，由 Agent 分区阅读全文和原始定位。
  3. 主 Agent 登记具体质量议题；一个国家×事件保留完整范围和反向分量。
  4. 先聚合区分解释，必要时取 cohort、明细与身份轨迹；共享查询不增加业务义务。
  5. 调查答卷提交后，主 Agent 独立阅读证据、复算并审核；必要时第三人复核。
  6. 核对抽查、历史回归、内部对账、发布承接和末次指纹，再生成报告与续跑状态。

七条审计主线

完整性、重复放大、身份连续性、数值守恒、时间序列、价格带、历史缺陷回归。

分类语义不做默认专项。映射引发丢数、重复、错联或守恒问题仍须核查。正文先说明宏观影响，用微观证据证明机制。

分母不能互换

对象含义
查询、事实与客观检查证明范围和材料覆盖，不是 Agent 深查清单
议题与独立范围具体质量疑问与必须回答的国家×事件合同
实际任务与主审真实分派和有效审核；提交、受阻、核实分别计数

普通市场变化不形成逐条解释债务；未回答的质量疑问继续。预算不足保存断点，外部缺证保留实际尝试及恢复条件。
